Duel Bot Wrapper is Omega Custom Duel BOT API of [Yu-Gi-Oh!](https://www.yugioh-card.com/en/) game written in [C#](https://dotnet.microsoft.com/en-us/languages/csharp). Compatible with [YGO Omega - The Ultimate Yu-Gi-Oh! Simulator.](https://omega.duelistsunite.org/)

## ✨ Features

- **Create your BOT**
  - It allows you to create and customize your own bot to interact with the game, automating actions like playing cards and responding to effects. "Create your bot" means building a personalized bot to suit your needs in the game. You can create it in any format (Master Duel, Rush Duel, Speed Duel...)
